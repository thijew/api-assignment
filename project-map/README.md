# 🖼️ RijksArt Explorer

Een simpele webapp om kunstwerken uit het Rijksmuseum te bekijken. Gebouwd met Node.js, Express en Liquid.

## 🚀 Features

- Overzichtspagina met kunstwerken
- Detailpagina met beschrijving en maker
- Data via de Rijksmuseum API

## 🔧 Gebruikte technologieën

- Node.js / Express
- Liquid template engine
- Rijksmuseum API

## 🧠 AI gebruik

Structuur en voorbeeldcode gegenereerd met hulp van ChatGPT, aangepast en verbeterd voor betere leesbaarheid en functionaliteit.
